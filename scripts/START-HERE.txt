ELLESON DOCS 0.2.0

WINDOWS
Extract the complete Windows ZIP. Run Elleson Docs.exe.
Install.cmd adds shortcuts and Windows Open with registration.
Open file accepts PDF, DOC and DOCX.

ANDROID
Install Elleson-Docs-0.2.0.apk on Android 8 or newer.
Choose Open documents on phone for independent PDF and DOCX use.
For live editing, keep Windows open and put both devices on the same Wi-Fi.
Choose Connect phone on Windows, then enter its address and pairing code
in Android. Either device can open and save the shared document.
To transfer independent phone edits, save them on the phone, connect,
and open that saved file from the phone.

TOOLS
View, search, thumbnails, bookmarks, document outlines and zoom.
Edit PDF changes existing text. Preview a change before applying it.
Original-font edits require available glyphs and room on the line.
Scan & OCR recognizes English, French or Spanish on a PDF page.
Scan document converts a photo into PDF, with manual straightening.
Add text, Draw, Highlight, Erase mark and Signature work on PDF pages.
Signatures use a larger pad, reusable device storage and placement sizes.
Organize pages rotates, deletes, reorders, extracts and combines pages.
Combination creates fixed pages, retaining visible answers and annotations.
Word Edit text enables paragraph edits. Select a paragraph to format fonts,
size, bold/italic, alignment or lists, or insert a table or image.
Save copy exports a separate file. Fixed PDF copy flattens form fields.
Print prepares current content for the system print workflow.
Files contains recent documents, pins and saved versions.
Tabs reopen saved files. One document is shared live at a time.
The latest editing session recovers after restarting.

LIMITS
Files must be smaller than 40 MB. Standalone Android supports PDF and DOCX.
Legacy DOC needs Windows and edited exports use DOCX.
Complex Word layouts, protected PDFs and some forms/fonts are unsupported.
OCR text uses an estimated font and needs visual checking.
Bookmarks and saved signatures stay on the device.
Advanced table editing and image resize handles are not included.
Erase and replace a signature to change its placement or size.
Local pairing uses HTTP, intended for a trusted local network.
Saved versions consume local storage. Export important files separately.
Physical Android camera, installation, touch, saving, networking and
physical printers still require hands-on validation.
